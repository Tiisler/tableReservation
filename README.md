# **Eestikeelne juhend**<br>
## **Eeltingimused:**<br>
    1. Arvutisse peab olema installitud Node.js
    2. Arvutisse peab olema installitud Java JDK 25.
    3. Soovitatav IDE: IntelliJ IDEA või VS Code (koos "Extension Pack for Java" mooduliga).

## **Käivitusjuhend:**<br>
### **Backendi käivitamine (Spring Boot):**<br>
    1. Ava projekt oma IDE-s.
    2. Oota, kuni IDE laeb Maveni sõltuvused.
    3. Käivita fail: backend_tableReservation/.../BackendTableReservationApplication.java.
### **Frontendi käivitamine (Vue.js):**<br>
    1. Ava uus terminaliaken ja liigu frontend kausta: "cd .\frontend_tableReservation\."
    2. Siseta käsk "npm install" (see laeb alla vajalikud raamistikud, sh Vue).
    3. Sisesta käsk "npm run dev".
    4. Ava brauseris aadress, mille terminal sulle annab (nt http://localhost:5173/).

# **English Guide**<br>
## **Prerequisites:**<br>
    1. Node.js must be installed on your computer.
    2. Java JDK 25 must be installed on your computer.
    3. Recommended IDE: IntelliJ IDEA or VS Code (with the "Extension Pack for Java" plugin).

## **Setup Instructions:**<br>
### **Starting the Backend (Spring Boot):**<br>
    1. Open the project in your IDE.
    2. Wait for the IDE to load Maven dependencies.
    3. Run the file: backend_tableReservation/.../BackendTableReservationApplication.java.
### **Starting the Frontend (Vue.js):**<br>
    1. Open a new terminal window and navigate to the frontend folder: "cd .\frontend_tableReservation\."
    2. Enter the command "npm install" (this downloads the necessary frameworks, including Vue).
    3. Enter the command "npm run dev".
    4. Open the address provided by the terminal in your browser (e.g., http://localhost:5173/).
